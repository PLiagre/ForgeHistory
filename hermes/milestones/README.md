# Jalons historiques

Ce dossier conserve les constats de jalons produits par l'ancien workflow
d'audit. Il n'attribue plus de rôle et ne déclenche aucune procédure.

Les mentions d'auditeur, de contre-auditeur, de porte ou de fusion dans les
fichiers datés décrivent le processus appliqué à l'époque. Elles sont
obsolètes et ne constituent pas des instructions actuelles.

Un nouveau jalon peut être documenté par n'importe quel contributeur ou agent
autorisé, avec les faits, commits et reports utiles. Aucune revue indépendante
ni automatisation particulière n'est requise.
