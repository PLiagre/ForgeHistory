# Briefs conservés

Chaque dossier sous `briefs/` décrit un lot et peut contenir ses livrables.
Ces fichiers restent présents sans réécriture afin de préserver l'historique
et les travaux déjà réalisés.

Les clauses anciennes qui attribuent un rôle, interdisent une action à un
acteur, exigent une relecture distincte ou imposent une porte de verdict sont
obsolètes. Elles documentent le processus de l'époque et ne gouvernent plus le
dépôt. Tout contributeur ou agent autorisé peut reprendre, amender, exécuter,
relire ou archiver un brief.

Les lots 001 à 032, retirés de l'arbre courant lors du dégraissage, restent
consultables au commit `da1596d` :

```bash
git show da1596d:harness/queue/briefs/011-sim-monde-vivant-amorcage/brief.md
git ls-tree --name-only da1596d:harness/queue/briefs
```
